# Response-to-reviewers template (P8 — after real reports arrive)

Structure per reviewer comment (never skip, never argue without evidence):

```
## Reviewer R, Comment C
> [verbatim comment]
**Response:** [agree / partially agree / respectfully disagree + reason]
**Action:** [revision id from revisions.json | explanation why no change, citing section/rule]
**Location:** ms_revN.txt, Section X, lines Y–Z (line numbers from the numbered file)
```

Rules:
1. Thank once at top; summary of changes (3–6 bullets) before point-by-point.
2. Every changed number must trace to a run stamp / table; no silent number edits.
3. Disagreements cite evidence (table/figure/line) and stay on-axis; concede small points fast.
4. New experiments only if reviewer asks AND data exist (RECS/ResStock public) — else propose
   as future work in Limitations and say so.
5. Attach: CHANGELOG.md excerpt + updated highlights if claims changed + new/renumbered figures list.
