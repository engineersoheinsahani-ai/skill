# 01 — Energy & Buildings: Guide for Authors (distilled, rule-id'd)
Source: sciencedirect.com/journal/energy-and-buildings/publish/guide-for-authors (fetched 2026-10).
Scope note: ENB covers energy use in buildings, building-stock modelling, ML/AI for
building energy, performance gap, retrofit evaluation — this manuscript sits inside scope.

## About / peer review
- ENB-REV-1 Single-anonymized review; editor desk-screen first; ≥2 independent reviewers.
- ENB-REV-2 Appeals: one formal appeal per Elsevier Appeal Policy; decision final.
- ENB-REV-3 Replication studies encouraged (cite original + deposit data).
- ENB-SCOPE-1 Fit test: contribution must address building energy use/performance;
  method-only ML papers must tie claims to building-stock decisions (axis law hook).

## Writing & formatting
- ENB-FILE-1 Editable .doc/.docx or .tex; PDF NOT acceptable as source; Word single-column.
- ENB-FILE-2 Remove strikethrough/underline unless scientifically relevant.
- ENB-LINE-1 **Journal-specific: continuous line numbers required.**
- ENB-SEC-1 Numbered sections; subsections 1.1, 1.1.1; abstract NOT inside numbering;
  cross-references by number, never "the text".
- ENB-ACK-1 Acknowledgements = separate section directly before reference list
  (language/editing help belongs here).
- ENB-APP-1 Appendices A, B…; Eq. (A.1); Table A.1; Fig. A.1.

## Title page
- ENB-TP-1 Title concise & informative; avoid abbreviations/formulae unless established.
- ENB-TP-2 Given + family names; order matches submission system.
- ENB-TP-3 Affiliations: lower-case superscript letters; full name + postal address + country.
- ENB-TP-4 One corresponding author; email on title page (published).
- ENB-TP-5 Present/permanent address as footnote (Arabic numerals) if changed.

## Abstract / keywords / highlights / graphical abstract
- ENB-ABS-1 Abstract ≤ **250 words**; stand-alone; state purpose, procedures, main findings
  (+ statistical significance where applicable), principal conclusions.
- ENB-ABS-2 Avoid references in abstract; if essential cite author+year in full.
- ENB-ABS-3 Avoid non-standard abbreviations; define at first mention inside abstract.
- ENB-KW-1 **1–7 keywords**; English; avoid multi-word ("and"/"of"); abbreviations only if established.
- ENB-HL-1 Highlights mandatory: separate editable file, file name contains "highlights".
- ENB-HL-2 **3–5 bullets, each ≤85 characters including spaces.**
- ENB-HL-3 Bullets capture novel results / new methods (discoverability).
- ENB-GA-1 Graphical abstract **mandatory at submission**; separate file.
- ENB-GA-2 Image **531 × 1328 px (h × w)** or proportionally more; readable at 5 × 13 cm.
- ENB-GA-3 Preferred types TIFF/EPS/PDF/MS Office; third-party material needs permission;
  GenAI use must follow Elsevier GenAI policy.

## Maths / tables / figures
- ENB-MATH-1 Equations editable text (not images); italics variables; exp for powers of e;
  consecutive numbering; solidus for small fractions.
- ENB-TBL-1 Tables editable text; cited in text; consecutive numbers; captions; notes below
  body; no vertical rules/shading; avoid duplicating results already in text.
- ENB-FIG-1 Artwork separate files; cited in text; numbered in order; logical names
  (Figure_1, Figure_2…); captions = brief title (not on image) + description; symbols explained.
- ENB-FIG-2 Photos ≥300 dpi (single col 1063 px / full page 2244 px); line art ≥1000 dpi;
  charts XLS/XLSX; annotated PPTX ≥300 dpi embedded; no low-res; no combined multi-images
  (except intended comparisons); colour accessible to colour-blind readers.
- ENB-AIART-1 GenAI may support explanatory diagrams & data-derived visualisations;
  NEVER create/alter primary observed/experimental images; disclose in caption + AI statement.
- ENB-SUPP-1 Supplementary cited in text, submitted together, captioned; appears as-is.

## Research data (journal enforces **Option C**)
- ENB-DATA-1 REQUIRED: deposit data in a relevant repository; cite & link dataset in article;
  if impossible, explain why in a statement.
- ENB-DATA-2 Data availability statement mandatory at submission (published on ScienceDirect).
- ENB-DATA-3 Dataset citation: authors, title, repository, version, year, persistent identifier;
  prefix `[dataset]`; link via repository banner / `Database: ID` format.
- ENB-DATA-4 Co-submission to Data in Brief / MethodsX encouraged (linked articles).

## References
- ENB-REF-1 At submission: any style **if consistent**; must include authors, titles, journal,
  year, volume, pages/article-number where applicable.
- ENB-REF-2 Journal style (applied at proof): numbered **[n]** in citation order; author names
  initials-first; journal names abbreviated per **LTWA** (portal.issn.org/ltwa); DOIs included.
- ENB-REF-3 Every list entry ↔ in-text citation (bidirectional); every reference real & complete.
- ENB-REF-4 `[dataset]` / `[software]` tags; web refs need full URL + access date;
  preprints marked with server name + DOI; "in press" = accepted.
- ENB-REF-5 Reference-manager templates via CSL (Mendeley); remove field codes before submission.

## Submission
- ENB-SUB-1 Checklist: corresponding author details; all files uploaded (artwork, tables,
  captions, supplementary); spelling/grammar checked; refs bidirectional; permissions obtained.
- ENB-SUB-2 Submit at submit.elsevier.com/ENB; system builds single PDF for review.
- ENB-SUB-3 Decision letters by email; revisions via same system; Article Transfer Service
  may suggest sibling journals (independent re-review there).
