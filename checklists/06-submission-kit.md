## Five pre-submission tips (Editorial Manager video, distilled) (KIT-TIP-*)
- KIT-TIP-1 Match scope & article type BEFORE upload; read aims & scope + recent similar papers.
- KIT-TIP-2 Complete every metadata field accurately (funding, conflicts, author order = system
  order, ORCIDs) — mismatches with files cause returns.
- KIT-TIP-3 Upload files in right categories; the system-built PDF must be checked page by page
  (broken equations/tables/figures are desk-reject bait).
- KIT-TIP-4 Suggest/oppose reviewers where asked (no recent co-authors, no same institution,
  no family); conflicts checked by editor.
- KIT-TIP-5 Run the journal checklist + spelling/grammar + reference bidirectionality LAST,
  after the built PDF looks right.

## Cover letter anatomy for ENB (KIT-COV-1)
1. Title + article type + "we submit to Energy and Buildings because …" (aims hook, 1 sentence).
2. 3-bullet contribution tied to building-energy decisions (axis law again).
3. Data/ethics line: public data sources, AI declaration present, no conflicts, funding line.
4. Reviewer suggestions (3–5, with emails, no conflicts) + opposed reviewers if any.
5. Standard declarations: not under consideration elsewhere; all authors approved.

## Post-acceptance promotion (KIT-POST-*)
- KIT-POST-1 Share Link = 50 days free access; circulate to co-authors, labs, socials.
- KIT-POST-2 Graphical abstract + highlights drive ScienceDirect discovery; reuse in slides/LinkedIn.
- KIT-POST-3 Link dataset DOI in profile/Mendeley; consider Data in Brief co-article for the
  pipeline artefacts (audit JSON schema, run manifests).
